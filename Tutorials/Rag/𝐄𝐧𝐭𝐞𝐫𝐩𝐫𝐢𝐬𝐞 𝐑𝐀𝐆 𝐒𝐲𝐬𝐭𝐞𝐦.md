THE END-TO-END FLOW

𝟏. 𝐑𝐀𝐆 𝐓𝐘𝐏𝐄𝐒
How the question gets processed before anything else:
- Multi Query
- RAG Fusion
- Decomposition
- HyDE
- Step Back

Each approach transforms the original question differently to improve retrieval quality downstream.

𝟐. 𝐑𝐎𝐔𝐓𝐈𝐍𝐆
Decides where the query goes:
- Logical Route: Chooses which database to query Graph DB or Relational DB.
- Semantic Route: Selects the right prompt template Prompt 1 or Prompt 2 based on query meaning.

𝟑. 𝐐𝐔𝐄𝐑𝐘 𝐂𝐎𝐍𝐒𝐓𝐑𝐔𝐂𝐓𝐈𝐎𝐍
Translates natural language into database-specific queries:
- Text-to-SQL: Natural language to SQL for relational databases or SQL with PGVector
- Text-to-Cypher: Natural language to Cypher query language for Graph DBs
- Self-query Retriever: Auto-generates metadata filters from the query

𝟒. 𝐈𝐍𝐃𝐄𝐗𝐈𝐍𝐆
How documents are stored and organized:
- Semantic Split + Special Embedding (colBERT etc): Meaning-aware chunking with specialized embeddings
- Multi Representation Indexing: Summaries and parent documents compressed into compact retrieval units (Dense X)
- Hierarchical Indexing (RAPTOR): Documents organized in nested clusters for multi-level retrieval

𝟓. 𝐃𝐀𝐓𝐀 𝐒𝐓𝐎𝐑𝐄𝐒
Three storage targets working in parallel:
- Graph DB
- Relational DB
- Vector Store

𝟔. 𝐑𝐄𝐓𝐑𝐈𝐄𝐕𝐀𝐋
Two post-retrieval optimization steps:
- Refinement: Filter and improve retrieved documents
- Reranking: Re-Rank, RankGPT, RAG-Fusion to rank or filter/compress documents based on relevance

𝟕. 𝐆𝐄𝐍𝐄𝐑𝐀𝐓𝐈𝐎𝐍
Active retrieval methods produce the final answer:
- Self RAG, RRR (Retrieve, Rerank, Respond), and other active retrieval patterns

𝟖. 𝐄𝐕𝐀𝐋𝐔𝐀𝐓𝐈𝐎𝐍
Measure quality continuously:
- RAGAS: RAG evaluation framework
- Grouse: Groundedness evaluation
- DeepEval: Comprehensive LLM evaluation

𝐖𝐇𝐀𝐓 𝐌𝐀𝐊𝐄𝐒 𝐓𝐇𝐈𝐒 𝐄𝐍𝐓𝐄𝐑𝐏𝐑𝐈𝐒𝐄-𝐆𝐑𝐀𝐃𝐄
Every stage has multiple options. The architecture does not lock you into one approach it lets you mix routing strategies, indexing methods, and retrieval techniques based on your data and use case.

𝐓𝐇𝐄 𝐏𝐑𝐈𝐍𝐂𝐈𝐏𝐋𝐄
A basic RAG system has three steps. 
An enterprise RAG system has eight and the five you add between question and answer determine whether your system is demo-ready or production-ready.
