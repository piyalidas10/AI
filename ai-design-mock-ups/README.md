# Build prototypes and production applications based on design mock-ups provided by the design team in the areas of Machine Learning and Generative AI.
You will take UI/UX designs (Figma, Adobe XD, wireframes, mockups) created by the design team and convert them into working software applications related to AI, Machine Learning, or Generative AI.

Examples:
- AI chatbot demo
- RAG search UI
- AI image generation interface
- Prompt playground
- Dashboard for ML predictions

> Prototype = fast experimentation to validate ideas.

“Production applications”
------------------------------------------------------------
Convert demos into real scalable enterprise applications.

That includes:
- authentication
- performance optimization
- deployment
- API integration
- testing
- monitoring
- security

Production apps are used by real users/customers.

“Based on design mock-ups”
------------------------------------------------------------
The design team gives:
- Figma designs
- UI screens
- workflows
- components

You implement them in code.

Typical stack:
- Angular / React / Next.js
- Tailwind / Material UI
- REST APIs / GraphQL
- WebSockets
